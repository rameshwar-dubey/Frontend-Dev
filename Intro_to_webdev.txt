Frontend development focuses on what users see and interact with directly in their browser 
   Technologies in Frontend-
	HTML ,CSS ,JavaScript ,Frameworks/Libraries :React ,Angular
   Example- When we open Amazon's homepage ,the search bar, product images, Add to cart button , navigation bar ,these all are the part of frontend.	
   
   Backend development handles what happens behind the scene , managing data, logic, user authentication , and communication between the database and the frontend.            
   Technologies in backend-
	Languages: Node.js, python, Java, PHP, Go, Ruby
	Database: MySQL, MongoDB, PostgreSQL
	Server: Apache, Nginx
   Example- When you log into Netflix , the backend checks your username and password, retrieves your watch history , and sends it to the frontend for display.

   Full-Stack development works on both frontend and backend , building the entire web application from the user interface to the server and the database.
   Technologies-
	MERN Stack- MongoDB, Express.js, React, Node.js
	MEAN Stack- MongoDB, Express.js, Angular, Node.js
   Example- If someone creates a blog websites where users can register ,write posts , and view others posts , and the person builds both the design and the database + logic , they
   are a full-stack developer.

🌐 CLIENT-SERVER MODEL

 ┌───────────────────┐
 │        CLIENT          │
 │ (Browser / App)        │
 │                        │
 │  - Sends Request       │
 │  - Displays Web Page   │
 └──────────┬────────┘
            │   HTTP Request
            ▼
 ┌───────────────────┐
 │        SERVER          │
 │ (Web Server + Backend) │
 │                        │
 │  - Processes Request   │
 │  - Fetches Data        │
 │  - Generates Response  │
 └──────────┬────────┘
            │   Database Query
            ▼
 ┌───────────────────┐
 │       DATABASE         │
 │ (Stores Data)          │
 │                        │
 │  - User Info           │
 │  - Products, etc.      │
 └──────────┬────────┘
            │   Data Returned
            ▲
 ┌───────────────────┐
 │        SERVER          │
 │  (Sends Response)      │
 └──────────┬────────┘
            │   HTTP Response (HTML/CSS/JS)
            ▼
 ┌───────────────────┐
 │        CLIENT          │
 │ (Displays Website)     │
 └───────────────────┘  

 1.	URL Entered	-You type a website address
 2.	DNS Lookup	-Domain → IP address
 3.	HTTP Request	-Browser requests the page
 4.	Server Processing	-Server prepares data
 5.	HTTP Response	 -Server sends back HTML/CSS/JS
 6.	Browser Rendering	-Browser builds and styles page
 7.	Page Displayed	 -You see the website

5. A web server is a software or hardware system that stores, processes, and delivers web pages to users over the internet or an intranet.
   When you type a website address in your browser:

	-> The browser sends an HTTP request to the web server.
	-> The web server processes the request.
	-> It sends back an HTTP response, which usually contains the requested web page (HTML, CSS, JS, images, etc.).

6.   -->Frontend Developer

	A frontend developer is responsible for everything the user sees and interacts with in a web application or website.

	Responsibilities:
		Design and implement user interface (UI) elements like buttons, forms, navigation bars, and layouts.
		Ensure responsive design so the site works on desktops, tablets, and mobile devices.
		Implement client-side functionality using JavaScript, CSS, and HTML.
		Optimize user experience (UX), load times, and accessibility.

	Tools/Technologies:
		HTML, CSS, JavaScript, React, Angular, Vue.js, Figma (for design references)

	Example:
		Making the login form and homepage layout look and work correctly.

     -->Backend Developer

	A backend developer works on the server-side logic and functionality that users don’t see. They ensure the app works properly by managing data and application logic.

	Responsibilities:
		Handle server-side programming to process user requests.
		Create and maintain APIs to communicate between frontend and database.
		Implement authentication, authorization, and security measures.
		Manage business logic and data processing.

	Tools/Technologies:
		Node.js, Python (Django, Flask), Java (Spring), PHP, Ruby, REST APIs

	Example:
		When a user logs in, the backend checks the username and password against the database and sends a response to the frontend.

     -->Database Administrator (DBA)

	A database administrator is responsible for designing, managing, and maintaining the database that stores all the data used by the application.

	Responsibilities:
		Design database schemas for efficient storage and retrieval.
		Manage data security, backups, and recovery.
		Optimize database performance and queries.
		Ensure data integrity and consistency.

	Tools/Technologies:
		MySQL, PostgreSQL, MongoDB, Oracle, SQL Server

	Example:
		Maintaining a user database so login credentials, profiles, and activity history are stored safely and can be retrieved quickly.

8.   Static Website

	A static website consists of fixed web pages coded in HTML/CSS.
	The content does not change unless a developer manually updates the code.

	Characteristics:
		-Simple and fast to load
		-No server-side processing required
		-Content is the same for every user
		-Usually smaller websites (brochure sites, portfolios)

	Technologies:
		HTML, CSS, JavaScript (basic)

     Dynamic Website

	A dynamic website generates web pages on-the-fly based on user interactions or data from a database.
	The content can change depending on user actions, preferences, or time.

	Characteristics:
		-Requires backend server and database
		-Content can be personalized for each user
		-More complex but interactive

	Technologies:
		Backend: PHP, Node.js, Python (Django/Flask), Java
		Database: MySQL, MongoDB
		Frontend: HTML, CSS, JavaScript

	Example:

		Amazon.com
		Users see different products, recommendations, and cart content based on their activity.
		Content changes dynamically for each user.
